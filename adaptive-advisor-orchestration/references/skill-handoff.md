# Sibling handoff

Read-when: Stage 0 detects the problem belongs to another packaged skill.

This skill's completeness is *method* completeness (gates, guards, evidence contract). Domain depth lives in sibling skills. Handoff is refuse-and-route, not mid-run Adapt, and not absorbing the sibling's files.

| Signal in the user ask | Route to | This skill still owns |
|---|---|---|
| dockerHDDM / HDDM / PPC kernel died / trial-level DDM fit | dockerhddm-skill | none, unless a real trade-off remains after the domain fix |
| methodology review / write the paper / submission pipeline | academic-paper-gated-pipeline (or the paper skill in use) | none, unless a methods trade-off needs a panel |
| no sibling | stay | Standard or Full ADR |

Do not emit HDDM `model.sample` code from this skill. Do not copy notebooks or literature into this tree.
